# Guias anteriores ("antes")

Quatro guias do relatório guardam a versão anterior das guias de análise. O desenvolvedor as mantém de propósito, para acompanhar a evolução do projeto. Estão ocultas, fora do navegador de páginas da Capa, e só se chega a elas por botões dentro delas mesmas.

| Guia | Versão atual | Visuais | Observação |
|---|---|---:|---|
| Comercial antes | [Comercial](../guias-do-relatorio/comercial.md) | 23 | Tem os botões "desempenho on" e "rank on" com marcadores inexistentes. |
| Analítico antes | [Analítico](../guias-do-relatorio/analitico.md) | 13 | Mesma matriz da versão atual, sem o menu recolhível. |
| Mapa Calor antes | [Mapa Calor](../guias-do-relatorio/mapa-calor.md) | 18 | Mesmos gráficos da versão atual, sem o menu recolhível. |
| Vendedores antes | [Vendedores](../guias-do-relatorio/vendedores.md) | 18 | Mesmos visuais da versão atual, sem o menu recolhível. |

Diferenças que o relatório mostra entre as versões: as guias atuais têm menu recolhível (marcadores `...MenuVisivel` e `...MenuOculto`) e usam as medidas com prefixo numérico; as "antes" usam botão de limpar filtros e os nomes antigos das medidas (ver [Nomes antigos de medidas](../medidas-dax/index.md#nomes-antigos-de-medidas-no-relatorio)).

Cada guia anterior navega só entre as guias "antes" e tem um botão para a Capa.
