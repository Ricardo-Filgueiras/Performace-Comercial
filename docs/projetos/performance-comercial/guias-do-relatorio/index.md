# Guias do relatório

O relatório `Performance Comercial.Report` tem **N guias**. Cada guia em uso tem uma página aqui, na ordem em que aparece no relatório. Guias ocultas e rascunhos estão no [Arquivo](../arquivo/index.md).

O nome do arquivo de cada página foi escolhido pelo assunto da guia, não pelo nome de exibição, para que o endereço não quebre se a guia for renomeada.
