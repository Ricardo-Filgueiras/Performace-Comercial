# Capa

## Para que serve

Página de entrada do relatório. É a única guia que aparece na barra de guias; as demais são abertas pelo navegador de páginas e pelos botões. Também traz os links do autor (*deduzido dos visuais*).

## Como ler

- O **navegador de páginas** lista as quatro guias de análise: [Comercial](comercial.md), [Analítico](analitico.md), [Mapa Calor](mapa-calor.md) e [Vendedores](vendedores.md). Ele está configurado para mostrar páginas ocultas e esconde a própria Capa e as quatro versões "antes".
- Três botões abrem páginas externas: o LinkedIn do autor, o repositório do projeto no GitHub e o canal do autor no YouTube.
- A guia não tem indicadores, filtros nem medidas.
